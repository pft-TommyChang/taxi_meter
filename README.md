# 台北跳表 / Taxi Meter

可橫向使用的 iOS 計程車跳表模擬器。第一版採富貴計費錶風格面板，使用 iPhone 的高精度 GPS 估算行駛距離、低速延滯時間與車資；每次跳表會以系統點擊音與觸覺回饋提醒。

## 費率設定

目前的 `TaipeiFareRules` 採大臺北現行規則：日間起跳 NT$85（1.25 km）、續程每 200 m NT$5、車速低於 5 km/h 時每 60 秒 NT$5。23:00–06:00 依上車時間判定，每趟加收 NT$20。

低速時以延滯時間取代距離跳表，避免兩者同時累加。原始 GPS 總距離仍會顯示在面板上。

## iOS 執行

```sh
flutter pub get
flutter run -d <ios-device-id>
```

首次啟動請允許「永遠」的精確位置，才能在鎖定或切換 App 時繼續記錄；iOS 會顯示背景定位指示。App 只支援橫向。真實 iPhone 的定位品質會受天空視野、都會高樓、車內擺放位置與省電模式影響；此 App 適合娛樂及自行比對，不是經檢定、可作為收費依據的計費器。

若 GPS 不可用，App 會提供模擬模式。開始後點上方「行駛公里」會以 80 km/h 前進，點「計程時間」則停止前進並累積延滯計時。

## 擴充方式

- 計費規則集中於 `lib/taxi_meter_controller.dart` 的 `TaipeiFareRules`，可新增城市規則類別。
- 面板外觀由 `MeterSkin` 抽象類別管理，第一版為 `FuguiMeterSkin`；新增面板不需改動 GPS 或跳表引擎。
